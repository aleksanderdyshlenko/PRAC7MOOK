Ответы на контрольные вопросы
1. Что такое JavaScript?
JavaScript — это язык программирования, который выполняется в браузере и делает веб-страницы интерактивными. С его помощью можно реагировать на действия пользователя, изменять содержимое и стили страницы, отправлять запросы на сервер и многое другое.

2. Чем отличается JS от HTML и CSS?

HTML — отвечает за структуру страницы (заголовки, абзацы, кнопки).

CSS — отвечает за оформление (цвета, шрифты, отступы).

JavaScript — отвечает за поведение (реакция на клики, изменение данных, анимации).

3. Как подключить JS к HTML?
Двумя способами:

Внутри HTML — через тег <script>...</script>.

Внешний файл (рекомендуется) — <script src="script.js"></script>.

4. Что такое переменная?
Переменная — это именованная «ячейка» памяти, в которой хранится значение (число, строка, объект и т.д.). Пример: let name = 'Алиса';

5. Разница между let и const?

let — значение можно изменять после объявления.

const — значение нельзя переприсвоить (константа). Но если это объект или массив — можно менять их содержимое.

6. Что такое функция?
Функция — это блок кода, который можно вызывать по имени многократно. Она может принимать параметры и возвращать результат.

javascript
function greet() { alert('Привет!'); }
7. Что такое событие?
Событие — это действие, которое происходит на странице: клик мышью (click), наведение курсора (mouseover), ввод текста (input), загрузка страницы (load) и т.д.

8. Как работает addEventListener?
Метод addEventListener привязывает функцию-обработчик к элементу и указывает, на какое событие реагировать:

javascript
button.addEventListener("click", function() { ... });
Синтаксис: элемент.addEventListener("тип_события", функция).

9. Что такое DOM?
DOM (Document Object Model) — это объектная модель документа. Браузер представляет HTML-страницу в виде дерева объектов, к которым можно обращаться и изменять их через JavaScript (document.getElementById, textContent, style и т.д.).

10. Как изменить текст элемента через JS?
Через свойство textContent (или innerHTML):

javascript
let text = document.getElementById("text");
text.textContent = "Новый текст";
